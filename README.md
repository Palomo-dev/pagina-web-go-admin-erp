# GO Admin ERP

Landing page pública de GO Admin ERP — plataforma empresarial todo en uno.

## Descripción

ERP completo para gestión de ventas, inventario, finanzas, recursos humanos y más.
Landing one-page con scroll fullPage, secciones de producto, reportes, finanzas, IA, integraciones y precios.

## Stack

- Next.js 14
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- framer-motion

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```
